Репозиторий предназначен для реализации проекта во втором спринте. Основная задача — разработка и обучение нейронной сети на основе архитектуры LSTM для генерации продолжения текста.

Примечание: Из-за технических сложностей с подключением к виртуальной машине обучение модели было выполнено локально на ограниченной части датасета (10 тысяч предложений). В связи с этим полученные метрики качества прогнозирования не отражают реальную эффективность модели. Прошу провести ревью  в таком виде. 
В рамках проекта выполнены следующие этапы:
 
 - Сбор и предварительная обработка текстовых данных: очистка, токенизация, формирование обучающей и валидационной выборок. На основе данных созданы объекты Dataset и DataLoader для эффективной загрузки в модель.
 - Реализация архитектуры LSTM с использованием фреймворка PyTorch.
 - Обучение модели. После обучения модель применяется для задачи предсказания текста. Оцениваются значения функции потерь (Loss) на обучающей выборке, а также метрики ROUGE и ACCURACY на валидационной выборке. Веса обученной модели сохраняются в файл .
Для сравнительного анализа аналогичная задача решается с использованием предобученной языковой модели distilgpt2. Для неё также рассчитываются метрики ROUGE на валидационной выборке.
.
